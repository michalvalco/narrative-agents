## The Narrative Agents Project

### Core Thesis
Traditional AI agents treat memory as storage—accumulating data for retrieval. This project challenges that assumption by implementing **Paul Ricoeur's narrative identity theory** as agent architecture.

Key insight: Human identity isn't the sum of experiences but the *story we tell about them*. We remember what matters to who we're becoming.

### What This Implements
- **Narrative Identity** (Ricoeur, 1992): We constitute ourselves through the stories we tell
- **Aristotelian Teleology**: Purpose (telos) shapes perception and memory
- **Virtue Ethics**: Character traits (hexis) emerge from repeated patterns
- **Heideggerian Phenomenology**: Distinction between what happens TO us vs. what defines us

## Philosophical Framework Reference

### Key Concepts

**Telos** (τέλος)
- Aristotelian concept: purpose/end goal
- In our implementation: 5 types (LEARNING, PERFORMING, CREATING, SURVIVING, EXPLORING)
- Same experience means different things based on agent's telos

**Hexis** (ἕξις)
- Aristotelian concept: disposition/character trait
- Emerges through repeated action, not programming
- Virtues and vices form from patterns

**Narrative Identity** (Ricoeur)
- Identity = coherent story we construct about ourselves
- Emplotment: organizing experiences into meaningful narratives
- Selective memory: we remember what contributes to our ongoing story

**Substantia vs. Accidentia** (Aristotle)
- Substantia: essential properties defining the agent
- Accidentia: incidental details that don't define identity
- Memory architecture: narrative_core vs. peripheral
